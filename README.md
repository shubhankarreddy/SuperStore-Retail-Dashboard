# 📊 Excel Sales Dashboard

An interactive **Excel Sales Dashboard** built to analyze sales performance, track key KPIs, identify trends, and provide business insights using **Power Query, Power Pivot, DAX, Pivot Tables, Pivot Charts, Charts, Slicers, and Filters**.

---

## 📌 Project Overview

This project demonstrates an end-to-end sales analysis workflow in Microsoft Excel.

The raw sales data was cleaned and transformed using **Power Query**, modeled using **Power Pivot**, and analyzed using **DAX measures**. Interactive visualizations, Pivot Charts, Slicers, and Filters were then used to create a user-friendly dashboard.

The goal of the dashboard is to help business users quickly understand sales performance and identify important trends and areas requiring attention.

---

## 🎯 Project Objectives

- Clean and transform raw sales data using Power Query.
- Build a structured data model using Power Pivot.
- Create DAX measures for important business KPIs.
- Analyze sales performance across different dimensions.
- Identify sales trends and patterns.
- Compare performance across products, regions, categories, or other business dimensions.
- Build an interactive dashboard using Excel.
- Enable users to filter and explore the data dynamically.
- Present business insights in a simple and easy-to-understand format.

---

## ❓ Business Questions

The dashboard was designed to answer questions such as:

1. What is the total sales/revenue?
2. How many orders or transactions were recorded?
3. What is the average sales value?
4. How are sales changing over time?
5. Which products generate the highest sales?
6. Which regions or categories perform best?
7. Which products or regions contribute the most to overall sales?
8. Are there any periods with unusually high or low sales?
9. How does sales performance vary based on the selected filters?
10. Which areas require further business attention?
